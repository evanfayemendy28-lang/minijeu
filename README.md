# Puissance 4

Petit Puissance 4 jouable à deux joueurs sur le même ordinateur.

## Lancer le jeu

1. Ouvre ce dossier dans Visual Studio Code.
2. Ouvre un terminal dans VS Code.
3. Lance `npm start`.
4. Va sur `http://localhost:8000` dans ton navigateur.

Si npm n'est pas installé sur ton ordinateur, tu peux aussi lancer directement :

```bash
php -S localhost:8000
```

## Fichiers

- `index.php` : structure de la page et génération du plateau.
- `style.css` : apparence du jeu.
- `script.js` : logique du plateau, des tours et des victoires.
- `package.json` : commandes npm du projet.
